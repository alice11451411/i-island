# 轻量匹配流程修复计划

目标：匹配完成先展示报告，生成与质检留在后台；等待和失败可恢复，匹配开关与服务端一致。用户已授权自主决策与继续优化，保持离线规则模式。

1. Web：复现匹配开启成功但生成失败后状态陈旧、跨页等待丢失。添加行为回归测试，再同步开启接口返回的 user，展示跨页短状态，重试保留本次授权；成功时仅在用户仍停留发起页面才跳报告。跨页则保留可主动打开结果的入口。失败提示不显示质检过程。
2. 小程序：先用现有 VM 测试复现开启后的失败和重复授权弹框。立即保存开启结果；busy 覆盖授权确认与生成，取消/失败恢复；成功直达报告。
3. 保留现有报告中的可选对话回看，前端不展示质检代码、模型推理或假进度。浏览器以本地虚构数据和模拟接口验证失败重试、延迟时导航、手机布局；不修改用户演示数据。
4. 跑客户端行为测试、完整 npm test 与 npm run check；记录验证结果。当前项目没有 Git 元数据，不执行提交或分支操作。

已完成：91 项测试全通过、静态检查通过，隔离浏览器验收 7 项通过；本轮独立代码复核无未解决项。结果见 docs/validation.md 和 docs/quiet-flow-browser-check.json。
